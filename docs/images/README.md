# 截图素材说明

将以下文件放入本目录，README 会自动展示：

| 文件名 | 用途 | 建议尺寸 |
|--------|------|----------|
| `main-dashboard.png` | 主界面与对局数据总览 | 1280×720 或 16:9 |
| `hextech-rating.png` | 海克斯评级与 AI 分析 | 1280×720 或 16:9 |
| `champion-rank.png` | 英雄排行榜与推荐 | 1280×720 或 16:9 |
| `career-stats.png` | 个人生涯与数据统计 | 1280×720 或 16:9 |
| `demo.gif`（可选） | 动态演示，引流效果更好 | 宽度 ≤ 1280px，≤ 5MB |

## 拍摄建议

- 使用深色主题界面，在 GitHub 白底上对比更清晰
- 打码或隐藏账号名、好友 ID 等隐私信息
- PNG 优先；GIF 控制在 10–15 秒内，突出核心功能
