# GitHub 仓库配置指南

推送代码前，按以下清单配置仓库，可显著提升搜索曝光与点击率。

## 1. 仓库 Description（简介）

复制到 **Settings → General → Description**：

```
英雄联盟海克斯大乱斗辅助工具 | 海克斯S/A/B/C评级 | AI对局分析 | 游戏内Overlay | 本地OCR零上传 | OP.GG数据
```

英文备选（面向国际服用户）：

```
LoL Hextech ARAM assistant | Hextech rating | AI match analysis | In-game overlay | Local OCR
```

## 2. Website（可选）

若有 B 站演示视频、文档站或 Discord，填到 **Website** 字段。

## 3. Topics（标签）

**Settings → General → Topics**，添加：

```
league-of-legends
lol
hextech-aram
aram
gaming-assistant
overlay
python
opgg
英雄联盟
海克斯大乱斗
```

## 4. Social Preview（社交预览图）

**Settings → General → Social preview**

- 推荐尺寸：**1280 × 640**
- 内容：Logo + 「伊芙琳助手」+ 核心卖点（海克斯评级 / Overlay）
- 分享链接到 Twitter、Discord 时会显示此图

## 5. About 区域

在仓库首页右侧 **About** 勾选：

- [x] Releases
- [x] Packages（若后续有）
- [ ] Wiki（可选）

## 6. 首次 Release 建议

1. 进入 **Releases → Create a new release**
2. Tag：`v1.0.0`
3. Title：`v1.0.0 - 伊芙琳助手首次发布`
4. 正文：复制 `docs/RELEASE_NOTES_TEMPLATE.md` 并填写
5. 附件：上传 `.zip` 绿色版 + 在 Release 说明里放主界面截图

## 7. Pin 到个人主页

在 GitHub 个人主页 **Customize your pins** 中 Pin 本仓库。
